## Лабораторная работа №4

### Взаимодействие процессов через отображаемые файлы

ФИО: Ильин Владислав Александрович

Группа: М8О-202БВ-25

Вариант: 9

### Цель работы

Организовать обмен данными между процессами через отображение файла в память.

### Постановка задачи

Задание из лабораторной №2: родитель получает имя файла и запускает дочернюю
программу. Она делит первое число каждой строки файла на остальные, при делении
на 0 оба процесса завершаются. Вместо pipe данные передаются через отображаемый файл.

### Алгоритм решения

1. Родитель открывает файл с числами и узнаёт его размер через `fstat`.
2. Создаёт временный файл через `mkstemp`, сразу удаляет имя через `unlink`
   и задаёт размер через `ftruncate` с запасом под все результаты.
3. Через `fork` и `execl` запускает ребёнка. `dup2` подставляет файл с числами
   в `stdin`, а временный файл — в `stdout`.
4. Ребёнок отображает временный файл через `mmap` с `MAP_SHARED`, построчно
   считает результаты и записывает их в отображение. При делении на 0 завершается с ошибкой.
5. Родитель ожидает ребёнка через `waitpid`, отображает тот же файл через `mmap`,
   выводит результаты и проверяет статус завершения. Освобождает память через
   `munmap`, закрывает дескрипторы через `close`.

### Ввод и вывод программы

```sh
cmake -S . -B build
cmake --build build
echo lab4/test.txt | ./build/lab4/lab4_parent
```

```text
child: division by zero, exit
10.000000
5.250000
42.000000
parent: child process failed, exit
```

### Вывод

Реализован обмен данными через отображаемый файл с `MAP_SHARED`.
Ожидание ребёнка через `waitpid` гарантирует, что родитель читает результаты
только после их записи. Временный файл удаляется сразу после создания.
